# Native layered design: document and rendering repairs

Building the Arabic GTA VI composition exposed three rendering defects and a host integration gap. The implementation reuses the existing schema-v2 bundle container and image renderer; it does not introduce a second scene model.

- `EditorSession::open_document` admits JSON or embedded-asset bundles with caller-owned limits. Bundle metadata and encoded resource budgets are admitted before replacing the session. Export preserves asset payloads after edits and undo/redo. Opening JSON clears resources from the previous document.
- Desktop Open accepts `.swv` and `.json`. Save preserves the current container. `--document <path>` opens a file in a new application process. This development host bounds files at 64 MiB, individual assets at 16 MiB, total encoded resources at 48 MiB, and decoded image dimensions at 4096 per side. Pixel decoding remains deferred until preview; successful open does not certify that every image is decodable.
- Image rendering previously painted intrinsic pixels into a node-sized rectangle. The corrected transform fits image pixel space into each node before applying its world transform and preview scale. The regression uses a two-color bitmap of different intrinsic dimensions, a reduced SVG, translation, scale 2, and outside-box assertions.
- PNG decoding expands indexed, transparent palette and low-bit grayscale input and strips 16-bit samples before RGBA conversion. Regressions cover palette transparency, one-bit grayscale and 16-bit RGB channel order.
- Text shaping previously selected variable-font coordinates but outline extraction always used the default font instance. Shaped runs now retain adapter-neutral F2DOT14 coordinates. Outline extraction and caching use the exact location selected by Parley. The regression checks separate regular/900 outlines and cache entries for pinned Latin and Arabic fonts.
- The UI previously supplied 480 × 320 for every document. A sole fixed root frame at the identity transform now supplies its actual artboard dimensions consistently to layout, preview and hit testing. Other documents retain the existing fallback. Opening a page fits it into the viewport.

Renderer fingerprints identify `adapter v2`. Both visual references were regenerated with the existing tolerance, and their current review status is pending. No previous human approval is claimed for the new pixels. These references remain test expectations, not a new product-design approval.

The design artifact is `output/designs/gta-vi-layered/GTA-VI-Arabic-Layered.swv`: 1080 × 1350, 22 scene nodes, seven editable text layers, five web image resources and two original SVG lighting resources. Its verification tool exercises title editing, cutout movement, undo, payload-preserving save/reopen and identical rendering after reopen. The preview comes from the actual editor service. The original flattened generated poster is not an asset in this native document.
