# Fonts

Reserved for pinned fonts used by text measurement, shaping, and golden renders.
No font fixtures are committed yet; the text adapter and visual M0 gate remain
incomplete.

Requirements:

- Only fonts with a license that permits redistribution and testing.
- Record each font's name, version, license, and source.
- Pin the exact files used by reference tests so results stay reproducible.

Add fonts only with the corresponding text/render acceptance tests.
